Desktop video workflow tool

Plan and organize your TikTok content

TikTok Batch Publisher is a Windows desktop tool for creators and social media teams. Organize video files from multiple folders, manage individual captions, group tasks by account, preview videos, and prepare publishing schedules.

Current features

Local video task library, per-video captions and hashtags, account labels, thumbnails, scheduling plans, and spreadsheet import/export.

Publishing integration

Official TikTok account authorization and Content Posting API integration are planned. The current desktop version does not automatically publish videos to TikTok.
