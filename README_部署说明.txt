TikTok Batch Publisher GitHub Pages 免费网站

1. 发布前，在三个 index.html 文件中搜索 [REPLACE WITH ...]，替换为真实运营者名称和支持邮箱。
2. 注册 GitHub，在 https://github.com/new 创建 public 仓库，名称 tiktok-batch-publisher。
3. 将本压缩包中的 index.html、style.css、terms 文件夹、privacy 文件夹上传至仓库根目录。
4. Settings > Pages > Deploy from a branch > main > /(root) > Save。
5. 等待部署，访问 https://你的用户名.github.io/tiktok-batch-publisher/
6. 条款地址：https://你的用户名.github.io/tiktok-batch-publisher/terms/
7. 隐私地址：https://你的用户名.github.io/tiktok-batch-publisher/privacy/
8. TikTok 要求核验 URL 所有权。进入 URL properties，优先尝试 URL prefix 核验，按平台要求上传验证文件。GitHub Pages 能否通过具体核验取决于 TikTok 提供的验证方式及 URL 路径。
9. 网站只是审核准备材料，不代表审核通过；正式提交前必须保证真实功能、演示、隐私政策一致。
